What this demo is, honestly

It's an off-the-shelf model

This runs COCO-SSD (MobileNet v2), a general-purpose detector trained on 80 everyday object classes. It is deliberately not a custom model — the point is to show a working pipeline in a hostile environment, not to claim a benchmark.

Client-side is the hard mode

Running inference in a browser tab means no GPU server, no batching, and whatever device the visitor happens to hold. Production work usually has more headroom than this — which is rather the point of showing it here.

The latency number is real

It is measured around the actual forward pass on your hardware, not a stored figure. It will differ between your laptop and your phone, and that variance is exactly what capacity planning has to account for.

What real work adds

A production system replaces this with domain-specific classes, an evaluation set drawn from your data, a calibrated threshold tied to your cost of error, and monitoring for drift once it is live.
